# 清湘 API 使用教程：注册账号、创建密钥并接入 CC Switch

> **运行环境**：Windows 操作系统、CC Switch v4.0.24、Codex 客户端
>
>
>
> **更新日期**：2026 年 11 月 3 日

CC Switch（简称 CCS）用于集中管理 AI 供应商与模型路由，实际的交互与代码补全在 Codex 客户端内进行。本方案无需连接 SSH，也无需部署 Docker。

## 一、安装 CC Switch 与环境准备

前往 CC Switch 官方发布页（GitHub Release），展开 **Assets** 列表，根据电脑架构下载安装包：
```
https://github.com/farion1231/cc-switch/releases#release-v4.0.25
```
| 文件名称 | 适用环境与建议 |
| --- | --- |
| `CC-Switch-v4.0.24-Windows.msi` | **推荐**：适用于大多数 Intel / AMD 处理器的 Windows 设备 |
| `CC-Switch-v4.0.24-Windows-Portable.zip` | Windows 免安装便携版，解压后直接运行 |
| `CC-Switch-v4.0.24-Windows-arm64.msi` | 搭载高通骁龙等 ARM 处理器的 Windows 笔记本或工控机 |
| `.sig` 后缀文件 | 校验签名文件，**非安装包**，无需下载 |

下载 `.msi` 文件后双击完成安装。在进入下一步前，请确认本地已正常安装 **Codex 客户端**。

## 二、注册账号与获取额度

1. **注册**：打开清湘 API 注册页面，填写邮箱与密码完成注册；已有账号可直接登录。
2. **初始化额度**：新账户默认初始状态为：
   - **账户余额**：`0`
   - **并发上限**：`1`
3. **分配额度**：注册完成后，将注册邮箱发送给管理员开通额度。

> **注意**：
>
>
>
> - 账户余额为 `0` 时，即使成功生成并配置了 API 密钥，调用接口仍会拦截报错（`403`）。
> - 平台显示的 `$` 仅为站内核算计费单位，扣费按实际 Token 消耗与模型倍率计算，并非直接向 OpenAI / ChatGPT 官方账户充值。

## 三、创建 API 密钥

1. 登录清湘 API 用户中心，依次点击 **「API 密钥」** → **「创建密钥」**。
2. 按如下规范填写：

| 配置项 | 推荐填写内容 | 说明 |
| --- | --- | --- |
| **名称** | 自定义（如 `Codex-Local` 或 `我的电脑`） | 用于区分不同设备调用 |
| **厂商** | `OpenAI` | 保持为标准 OpenAI 兼容规范 |
| **分组** | `oaigpt` | 匹配对应模型调用分组 |
| **其他选项** | 保持默认 | 初次使用无需特殊配置 |

1. 创建成功后，**立即完整复制生成的 API 密钥**（形如 `sk-...`）。

> **说明**：密钥弹窗中的“额度限制”仅代表该密钥的**消费上限**，不会给主账户增加可用余额。若主账户余额为 0，即便将该密钥上限设置为 100，依然无法调用。

## 四、接入 CC Switch

### 方式 A：一键协议导入（推荐）

1. 在网页端的密钥列表中，点击该密钥右侧的 **「导入到 CCS」**。
2. 浏览器弹出外部应用唤起提示时，点击 **允许** 打开 CC Switch。
3. 在 CC Switch 弹出的配置导入窗口中，核验信息并确认保存。

### 方式 B：手动添加配置

若浏览器未触发唤起，可在 CC Switch 中依次点击 **「Codex」** → **「添加供应商」** → **「自定义配置」**，对照下表填入：

| 配置字段 | 填写内容 | 注意事项 |
| --- | --- | --- |
| **供应商名称** | `清湘 API` | 用于本地列表区分 |
| **API Key** | 填入本站生成的完整密钥 | 确保前后无多余空格或换行 |
| **Base URL / API 地址** | `https://api.luowanqingxiang.xyz/v1` | **末尾必须且只能有一个 `/v1`** |
| **模型 (Model)** | `gpt-6-astra` | 勿用导入模板默认的 `gpt-5.5` |
| **Wire API / 接口协议** | `responses` | 确保协议匹配 |
| **上游格式**（如有） | `Responses` | 匹配上游数据封装 |

> **Base URL 避坑要点**：
>
>
>
> - 切勿填写注册页面、登录页面或用户中心前台 URL。
> - 切勿填写 `127.0.0.1` 或 `localhost`。
> - 检查路径结尾，避免重复拼接成 `/v1/v1`。
> - 地址末尾无需手动添加 `/responses` 或 `/chat/completions`。

#### 高级编辑模式代码（JSON / TOML）

若 CC Switch 呈现为代码编辑窗口，请在对应区域填入以下配置片段（**仅配置当前供应商，无需覆盖全局配置文件**）：

**API Key 配置（JSON 区域）：**

```
{
  "OPENAI_API_KEY": "你的完整API密钥"
}
```

**模型与地址配置（TOML 区域）：**

```
model_provider = "qingxiang"
model = "gpt-6-astra"

[model_providers.qingxiang]
name = "清湘 API"
base_url = "https://api.luowanqingxiang.xyz/v1"
wire_api = "responses"
requires_openai_auth = true
```

## 五、启用与连通性测试

1. **启用配置**：在 CC Switch 中保存配置后，选中清湘 API，点击 **「启用」**（或「使用」）。
2. **重启客户端**：完全退出并重新打开 **Codex 客户端**，确保加载新代理环境。
3. **发送测试消息**：新建空白会话，发送测试指令：

   ```
   请只回复 OK。
   ```
4. **校验调用日志**：正常收到回复后，返回清湘 API 用户中心的 **「使用记录」** 页面，确认是否存在刚刚发起的调用日志及扣费明细。

> **提示**：新账号默认并发上限为 1。首次测试请等待单个请求完全响应结束，切勿多窗口同时发起请求。

## 六、常见问题排查

| 报错现象 / 状态码 | 核心原因 | 解决方案 |
| --- | --- | --- |
| **点击「导入到 CCS」无反应** | 客户端未后台运行 / 浏览器弹窗拦截 | 先手动打开 CC Switch；允许浏览器唤起外部协议；或改用“方式 B 手动配置”。 |
| **`401 Unauthorized`** | 密钥失效或未完整填入 | 检查密钥是否完整复制（无首尾空格）；确认该 Key 在管理后台未被禁用或过期。 |
| **`403 INSUFFICIENT_BALANCE`** | 账户余额耗尽或未充值 | 账户可用余额不足，请联系管理员分配使用额度。 |
| **`404 Not Found`** | 路由请求地址错误 | 检查 Base URL 是否错漏或多加了路径（如 `/v1/v1` 或尾部附带 `/chat`）。 |
| **提示模型不存在 / 不可用** | 模型代号填写错误 | 将模型名称修正为当前已支持的 `gpt-6-astra`（检查字母大小写及横杠）。 |
| **`429 Too Many Requests`** | 触发并发或限频保护 | 默认并发为 1，需等待上一个任务输出完毕后重试；降低调用频率。 |
| **`502` / `503 Bad Gateway`** | 网关异常或上游链路抖动 | 稍后重试；若持续发生，记录报错时间点与返回的 `Request ID` 联系管理员排查。 |

## 七、安全与密钥保管

- **一人一密**：严禁私下共享账号或密钥；请勿将包含密钥的导入链接、配置文件或未打码的配置截图发布至社交群组、技术博客或公开代码仓库。
- **泄露处置**：一旦出现密钥泄露风险，请立即进入平台用户中心 **禁用或删除** 该密钥，重新创建新密钥并在 CC Switch 中同步替换。
