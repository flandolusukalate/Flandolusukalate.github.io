## 项目简介

Flandolu's Space 是本站本身。设计目标是将个人博客、项目作品和生活记录整合在一处，同时保留精致的二次元幻想视觉风格。

## 计划与功能

- Markdown / MDX 内容系统
- 手机与桌面端响应式布局
- 静态搜索、文章目录和 RSS
- 明暗主题与低负担动画
- GitHub Actions 自动部署

目前它仍在开发与完善中，后续会记录设计调整和实际遇到的问题。
