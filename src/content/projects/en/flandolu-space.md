## About the project

Flandolu's Space is this website itself. The design aims to bring together a personal blog, project portfolio, and everyday updates while retaining a refined, anime-inspired fantasy style.

## Plans and features

- A Markdown / MDX content system
- Responsive layouts for mobile and desktop
- Static search, article tables of contents, and RSS
- Light and dark themes with lightweight animations
- Automated deployment with GitHub Actions

The site is still being developed and refined. Future notes will document design changes and problems encountered along the way.
